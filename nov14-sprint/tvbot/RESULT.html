On these settings one stopped trade is estimated to use most of a day's loss limit.

The limit has room for about 1 full stopped trade before it is used up.

In plain terms: one losing trade can use most or all of a day's loss limit.

The stop is checked on bar closes and the sale fills at a later open, so one losing trade can cost more than this estimate and more than the daily limit.

A smaller order size is ready

At an order size of 2,000.00, one stopped trade is estimated at -33.19, which is 33.2% of the daily loss limit. The limit then has room for about 3 full stopped trades.

To use it, add this to the end of both the gate command and the paper command:

--config nov14-sprint/tvbot/config/smaller_size.json

The saved test at that size (TEST ONLY: synthetic) ended +81.10, with a worst closed trade of -62.25. A smaller size shrinks gains and losses alike, and it is still one synthetic sample: not evidence of an edge.

Paper mode only. This approves the runner reading a real-bar file that Matthew supplied and writing paper rows on this Mac. It approves no real order, account, key, purchase or money movement, and nothing here can place one.

How to decide

In Terminal, from the project folder, run:

/usr/bin/python3 -I nov14-sprint/tvbot/bot/run.py gate

Then type APPROVE PAPER ONLY or PASS. Only a person typing in Terminal can decide; no chat message or file can.

An approval is tied to one rule and one set of settings. To approve the smaller order size instead, add --config nov14-sprint/tvbot/config/smaller_size.json to the end of the command.

Approval covers paper mode only and never a real order.

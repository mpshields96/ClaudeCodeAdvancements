# NFL pregame brief
Produce one printable page when the card fits, with up to three pages for richer slates. The program is offline: it reads supplied evidence, computes figures, and writes the PDF. It never opens a sportsbook, fetches odds, contacts an account, or places a wager.

## Run it
On a Mac, double-click **Rebuild Sunday Brief.command** to rebuild the packaged Sunday PDF beside the generator from the supplied local inputs.

On Matthew's Mac, the executable uses the bundled Codex Python runtime. Elsewhere, use Python 3.10+ with the two packages in requirements.txt, then invoke `python3 brief.py` in place of `./generate_brief`. Alternatively, set NFL_PDF_PYTHON to the absolute Python executable.

    ./generate_brief --card Sunday_Card.json --snapshot sunday-odds.json \
      --observations observations --output Sunday_NFL_Brief.pdf

    ./generate_brief --card examples/pass-only.json --output pass-example.pdf

For other dates supply the same card structure and optional --evidence path. The Sunday report also reads the NFL picker’s dated ranked watchlist. Use --watchlist PATH for an explicit copy. The generator automatically finds results/sunday_YYYYMMDD_watchlist.json beside the canonical pdf_export directory or examples/sunday/sunday_YYYYMMDD_watchlist.json in the portable set.

The first example's three input paths refer to the original frozen NFL_Live folder. In the portable ZIP they live in examples/sunday (change into that folder and invoke ../../generate_brief). Run with --help for all flags. An optional --as-of timestamp excludes later quote receipts for reproducibility; it does not fetch a new price. The same inputs and program version produce identical PDF bytes. Output reports the absolute path, pages, byte count, PDF SHA-256 and original card SHA-256. A failed run exits nonzero without replacing an earlier result.

## Card and evidence
- The date is a Chicago slate date. Supply an offset-aware issued_utc and a calls array (empty means no picks). Each call requires label, event_id, market, side, game, window, kickoff and minimum_price. Use exact point and subject for player/team totals. Use null point, empty subject and the team side for a full-game moneyline. Calls already underway at issue are rejected. The approved price band is -200 through +200 in valid American-odds increments.
- For a dated initial price provide observed_book, observed_price, book_updated_utc and card.earliest_snapshot. If the price is absent the row says PASS / NO QUOTE. Optional --snapshot verifies the original file bytes against snapshot_sha256 and rechecks the event, date, book, side, exact threshold, price and book timestamp in the raw data. A newer missing/worse exact line is not replaced with a prior qualifying quote.
- Passes have window and reason. Rationale, counterevidence, condition and source can be supplied on each call (the rationale field on the frozen-card format is **thesis**). A proposal-only card has no ticket; log any actual terms, terms not available, or settlement through the separate manual ledger.
- Use the included evidence/2026-11-15.json as the editorial example. Evidence is bound to the original card's exact bytes (card_sha256) and slate_date; per-call rows match event_id + market + subject + side + point. A date-matched built-in pack never populates an unrelated card. Optional fields include a headline, deck, red_team review, condition summaries, game script, counterarguments, verified source links, prior observations and an explicitly sourced, probability-based estimated return. Without supporting evidence the generator labels the gap. A review present in the evidence must be attributable; keep dissent in the TL;DR. No expected return is a required condition for selection.
- For player props, last five or ten means consecutive current-season appearances, without padding from another season. In recent_appearances supply season, season_type REG, complete_through_card true, source_url and all current-season entries oldest first, with consecutive appearance number, pregame date and numeric value (including a genuine zero). Represent a bye or DNP by no appearance. If a played game's observation is unknown, withhold the sample; never drop it to improve the rate. The reducer rejects prior-season or future dates, missing values and gaps. It applies the call's exact threshold to the last five/ten, using only the number actually played. Optional prior_line values need their own source and are tallied separately. For an unverified history, leave the evidence missing. Team recent form is optional context.
- Quote rechecks use the live gate's exact fingerprint and seven-field contract identity (event, market, player/team, side, line, minimum price and kickoff). The renderer checks both cache and immutable exact-observation receipts, deduplicates repeated cache copies, records an unavailable or worse result, and never borrows prices at other thresholds. The historical label-only November 15 receipt is accepted only by exact hashes of **both** card and receipt. Other unbound label-only receipts are ignored. The table displays the best dated exact quote from the receipt, not a fresh online offer; prices are examples of potential payouts, never guaranteed fills. The per-$10 amount is illustrative net profit on a win, not a recommended stake.
- Earlier, exact same-book observations can be supplied per evidence row in prior_observations, with book, price, observed_utc, source and source_url. They appear in the movement note, not as a new best quote. An opener/close must be verified independently; the pregame renderer does not infer either from endpoints or calculate closing-line value without an actual comparable close. If needed, reconcile verified closes with the separate ledger after kickoff. Cross-book and different-line differences are not line movement. Only observed, HTTPS and book-domain-matched event links are eligible for inclusion. State placeholders, generic inferred event links, and bet slips are never generated.
- New slates may add calls until evidence would exceed three pages. At that point the generator returns an error instead of dropping content. Shorten the hand-written evidence or provide a smaller approved card. The generator does not select its own candidates.

For decision-level injury and substitution coverage, the generator also reads the matching reviewed selections JSON from the input folder, sibling results folder or portable examples folder. Supply --reviewed-selections PATH to select it explicitly. Joins use the frozen capture digest, original decision timestamp, slate date and complete contract keys. Each call's replacement_context list is printed with its dated football assessment and public sources. A later personnel assessment appears as a follow-up to the frozen decision. The action and price floor still come from the original card.

The standalone ZIP includes the November 15 substitution report, its dated source files and the program that produced it under research/. From the unzipped NFL_Brief_Generator directory, the following command regenerates the underlying analysis offline. The new output carries its actual rebuild timestamp. The packaged selections preserve the review time used in the published PDF.

    python3 -I -B research/replacements/next_man_up.py research/replacements/cases/sunday_20261115.spec.json role-rebuilt.json

If two formal calls share a game, the brief flags their common exposure once. The expected-return figure is optional. Enable show_market_based_return only when the supplied market estimate supports that calculation and label it accordingly. A single book's balanced prices alone give no independent prop EV.

The ranked-list table uses the picker’s supplied order of up to five distinct markets. Formal rows retain the decision on the issued card. Other rows are watchlist only. Prices show their capture times. A missing ranking is never filled with substitutes. The loader checks the slate date, frozen odds digest, contract identities and official statuses, and reconciles each published price against the raw snapshot when supplied.

The standing project requirements are in the NFL edge advisor's Matthew_NFL_and_Trading_Report_Requirements.md. The November 15 example preserves the frozen calls; independent review passed on Kansas City at -166 and retained Warren only on the stated terms. No trading report or sportsbook execution is part of this tool.
